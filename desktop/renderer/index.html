Cloudflare 隧道

把本地 Web 服务发布到公网，无需公网 IP

傻瓜教程 · 手把手配置 {{ tutorialOpen ? '收起' : '展开' }}
方式一：快速隧道 30 秒上手
  1. 确认「Web 打印服务」正在运行（概览页可见）。
  2. 点下方「第 0 步」下载 cloudflared（已装可跳过）。
  3. 「隧道模式」选 快速隧道，目标地址保持 http://127.0.0.1:3000。
  4. 点 保存并启动，几秒后出现 https://xxxx.trycloudflare.com 公网地址。
  5. 点「复制」把地址发给需要打印的人即可（地址每次重启会变化）。
方式二：命名隧道（固定域名，推荐长期使用） 需要域名
  1. 注册/登录 Cloudflare，并按提示把域名接入 Cloudflare（修改域名 NS 服务器）。
  2. 进入 Zero Trust → Networks → Tunnels，点 Create a tunnel，类型选 Cloudflared。
  3. 给隧道起名并创建，复制页面给出的 Tunnel Token（一长串字符）。
  4. 在该隧道的 Public Hostname 点 Add：Subdomain 自定义（如 print），Domain 选你的域名，Type 选 HTTP，URL 填 127.0.0.1:3000。
  5. 回到本应用：「隧道模式」选 命名隧道，粘贴 Token，点 保存并启动。
  6. 浏览器访问 https://print.你的域名 即可。
安全建议与排错
  1. 网页默认账号 admin / admin123，请登录后尽快在「用户管理」中修改。
  2. 可在 Cloudflare Access 中为域名添加邮箱验证等策略，多一层保护。
  3. 打不开时先看下方「cloudflared 日志」，常见原因是端口不对或 cloudflared 路径错误。
