# Cloudflare Tunnel 傻瓜教程

本教程手把手教你把「WebPrint 打印助手」的网页打印界面安全地发布到公网，**不需要公网 IP、不需要在路由器上开端口**。

> 应用内也有同样的分步教程：打开应用 → 左侧「Cloudflare 隧道」→ 展开「傻瓜教程」。可以边看边点，无需来回切换。

## 前置条件

1. 应用里的「Web 打印服务」正在运行（默认 <http://127.0.0.1:3000>）。
2. 已下载 `cloudflared`：在应用「Cloudflare 隧道」页点 **下载**，或到 [官方下载页](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/) 下载 `cloudflared-windows-amd64.exe`。
3. 使用**命名隧道**时，需要有一个已托管到 Cloudflare 的域名。

---

## 方式一：快速隧道（30 秒上手，适合临时使用）

> 优点：零配置，立刻可用。缺点：公网地址是随机的，且每次重启都会变化。

1. 打开应用 → 左侧「Cloudflare 隧道」。
2. 若提示「未找到 cloudflared」，点 **一键下载并开启**：应用会自动下载 cloudflared（官方源不可用时**自动切换镜像**），并自动配置快速隧道。
3. 也可以手动：点 **下载** 获取 cloudflared，或用 **浏览** 指定已有的 `cloudflared.exe`。
4. 「隧道模式」选择 **快速隧道**。
5. 「目标地址」保持默认 `http://127.0.0.1:3000`（这是本机网页打印服务）。
6. 点击 **保存并启动**。
7. 几秒后，页面上方出现绿色地址，形如：

   ```
   https://random-words-1234.trycloudflare.com
   ```

8. 点 **复制**，把这个地址发给需要打印的人，对方在浏览器打开即可看到打印页面。

> 应用内提供两个快捷按钮：
> - **刷新重建**：关闭当前快速隧道并重新建立，几秒后会生成一个**新的**公网地址（地址失效或想换一个时使用）
> - **关闭快速隧道**：立即停止对外服务

> 提示：地址每次重启应用都会变；需要固定地址请用「方式二」。

> ⚠️ **快速隧道免责声明**：快速隧道（`*.trycloudflare.com`）由 Cloudflare 免费提供，公网地址随机且不固定，可能随时失效、中断或无法访问，**可用性不作任何保证**。请勿用它传输机密或敏感文件。因使用快速隧道产生的任何风险与后果，均由使用者自行承担；如需稳定、可自定义域名，请使用「方式二 · 命名隧道」。

## 方式三：已经用 `cloudflared service install` 装过（Windows 服务）

如果你之前用这条命令配置过隧道：

```powershell
cloudflared.exe service install eyJhIjoi....（一长串 Token）
```

说明 cloudflared 已经作为 **Windows 系统服务** 常驻运行。此时**不需要**在应用里再启动一次，否则会出现重复连接器 / 报错。应用已针对该场景做了兼容：

1. 应用会自动检测名为 `cloudflared` 的 Windows 服务：
   - 若服务正在运行，应用会显示「隧道由系统托管」，**不会重复启动**，也不会报错。
2. 如果你想改用应用内管理：
   - 先把**整条命令**（`cloudflared service install eyJ...`）或其中的 Token 粘贴到「Tunnel Token」输入框，应用会自动提取 `eyJ...` 部分；
   - 点 **安装为 Windows 服务** 按钮（等同执行该命令，需以管理员身份运行）；
   - 需要撤销时点 **卸载系统服务**。
3. 想彻底改由应用直接启动连接器：先「卸载系统服务」，再回到方式二的第 4 步粘贴 Token 并「保存并启动」。

> 排错提示：Token 无效、隧道未配置 Public Hostname、或系统服务与应用同时抢一个隧道，都会在「cloudflared 日志」中看到原因。

## 进阶：把打印服务（8081）也通过「域名 + 路径」暴露

默认 Web 服务与打印服务都在同一台机器，Web 服务用 `http://127.0.0.1:8081` 就能调用打印服务，**通常不需要暴露 8081**。

只有当「Web 服务」部署在另一台机器/云端，需要跨网络调用你本机的打印服务时，才把 8081 暴露出去。推荐用 **路径前缀** 的方式：

1. 在应用「设置」页，把「打印服务路径前缀」填为 `/agent`，并设置一个**强访问令牌**（访问令牌输入框）。
2. 打开同一个（或新建）Cloudflare Tunnel 的 **Public Hostname**，添加：
   - Subdomain / Domain：例如 `print` + 你的域名
   - **Path**：`/agent`
   - **Type**：`HTTP`
   - **URL**：`127.0.0.1:8081`
3. 在**远端**的 Web 服务里，把 `HOST_PRINT_API` 设为 `https://print.你的域名/agent`、`HOST_PRINT_TOKEN` 设为同样的令牌。
4. 验证：浏览器访问 `https://print.你的域名/agent/health`，应返回 `{"ok":true,...}`。

> ⚠️ 安全：打印服务一旦暴露到公网，**必须设置访问令牌**，否则任何人都能提交打印任务。可在 Cloudflare Access 再加一层登录保护。

> 原理：Cloudflare 会把路径原样转发给源站，所以应用内置的打印服务同时支持根路径和自定义前缀，前缀填 `/agent` 即可对上。

## 方式二：命名隧道（固定域名，推荐长期使用）

### 第 1 步：把域名接入 Cloudflare

1. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)。
2. 点 **Add a site**，输入你的域名，按提示把域名的 **NS 服务器**改为 Cloudflare 给出的两个地址（在你的域名注册商处修改）。
3. 等待生效（通常几分钟到几小时），域名状态变成 **Active**。

### 第 2 步：创建隧道并获取 Token

1. 在 Cloudflare 控制台左侧进入 **Zero Trust**（首次使用需按提示选择免费套餐）。
2. 进入 **Networks → Tunnels**。
3. 点 **Create a tunnel**，连接类型选 **Cloudflared**，点 Next。
4. 给隧道起个名字（如 `webprint`），点 Save。
5. 安装方式选择页面会显示一条命令，其中 `--token` 后面那一长串字符就是 **Tunnel Token**，复制它。
   - 形如：`eyJhIjoi....很长....`
   - 你**不需要**在电脑上手动运行这条命令，本应用会用它启动隧道。

### 第 3 步：配置公网域名指向本地服务

1. 在该隧道详情页切到 **Public Hostname** 标签。
2. 点 **Add a public hostname**，填写：
   - **Subdomain**：自定义，如 `print`
   - **Domain**：选择你的域名
   - **Type**：`HTTP`
   - **URL**：`127.0.0.1:3000`
3. 保存。此时访问 `https://print.你的域名` 就会被转发到本机的网页打印服务。

### 第 4 步：在应用中使用 Token

1. 回到应用「Cloudflare 隧道」页。
2. 「隧道模式」选择 **命名隧道**。
3. 把第 2 步复制的 **Tunnel Token** 粘贴到输入框。
4. 点 **保存并启动**。
5. 状态变为运行中后，浏览器打开 `https://print.你的域名` 即可使用。

## 安全加固（强烈建议）

1. **改掉默认密码**：网页默认账号 `admin / admin123`，登录后进入「用户管理」尽快修改。
2. **Cloudflare Access**：在 Zero Trust → **Access → Applications** 中为你的域名添加应用，配置邮箱验证码 / Google / GitHub 等登录策略，只有通过验证的人才能访问。
3. **只开必要端口**：网页与打印服务默认只监听 `127.0.0.1`，无需在路由器放行任何端口。

## 常见问题（FAQ）

**Q1：点启动报错「cloudflared 未找到」？**
在应用里点「下载」自动获取；或点「浏览」手动选择 `cloudflared.exe` 路径。

**Q2：地址能生成，但打开显示 502 / 无法访问？**
- 确认「Web 打印服务」在运行（概览页）。
- 命名隧道检查 Public Hostname 的 URL 是否为 `127.0.0.1:3000`。
- 查看应用内「cloudflared 日志」定位原因。

**Q3：公网地址每次重启都变？**
那是快速隧道。需要固定地址请使用命名隧道（方式二）。

**Q4：公司网络打不开？**
部分网络限制 Cloudflare，可换网络，或改用其它内网穿透方案。

**Q5：如何停止对外服务？**
在「Cloudflare 隧道」页点 **停止**，或直接退出应用。

**Q6：我用 `cloudflared service install eyJ...` 装的隧道，加进应用报错？**
应用已兼容：会自动识别该 Windows 服务并显示「系统托管」，不再重复启动。也可以把整条命令粘贴进 Token 框（会自动提取 Token），或直接用应用里的「安装为 Windows 服务 / 卸载系统服务」按钮。
